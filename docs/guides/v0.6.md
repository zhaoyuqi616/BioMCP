# BioMCP v0.6 single-gene dashboard

Multi-gene comparison and its MCP tool have been removed. Enter one gene per search.

The Overview summarizes identity, HPA expression, UniProt protein data, disease/drug counts, genomic archive context and literature coverage. Diseases and Drug Targets have dedicated evidence tables. Detailed evidence remains in Raw JSON.

Diseases shows up to ten direct Open Targets associations, scores and contributing evidence types. OMIM retains its explicit credential-gated state. Scores do not establish causality or individual risk.

Drug Targets shows modality-specific tractability and up to twenty drug/candidate records, prioritizing approval-stage records. The source clinical stage is separate from FDA approval. At most five displayed ingredients are checked against openFDA Drugs@FDA. An exact ingredient or generic-name match and an AP submission are required to display an ingredient approval record. This does not verify target-specific indication, continued marketing or current availability. Unmatched names, provider failures and unchecked rows remain unverified. Salt-name differences can prevent a match. Empty evidence and unavailable providers are explicitly distinguished.

Run python scripts/check.py for automated validation. Live validation uses SPP1 as an investigational-candidate example and EGFR as an established drug target. OMIM requires an authorized key for live validation. Local dashboard authentication and existing hosted/private-data release gates still apply.
