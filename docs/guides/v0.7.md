# Explore a gene in v0.7

Search **SPP1** in the local dashboard. Core gene information appears first. Once enrichment finishes, open **Evidence explorer**. The Tissue RNA view shows up to 15 measured tissues ranked by nTPM. When HPA omits tissue-specific nTPM values, BioMCP checks the gene’s consensus tissue RNA record. All retrieved measurements remain available in Evidence records. For example, TSP1 resolves to THBS1. The disease matrix shows Open Targets association components by evidence category. The drug plot groups candidates by their reported clinical stage and FDA verification status. Hover to inspect values, zoom the figures, or use the drug legend to filter groups.

The evidence table provides a text alternative. Use **Inspect evidence record** to inspect the value, source link, retrieval time and context. Select an available NCT identifier and click **Retrieve study** to fetch trial status, phase, interventions and the update date from ClinicalTrials.gov. The trial is evidence of a study, independent of regulatory approval.

Open **Sources** to review coverage. ClinGen can return no gene–disease validity curation for a gene. OMIM can be unconfigured independently of other sources. Bounded FDA checks can leave individual drugs unverified. Refresh Diseases or Drugs to retrieve that section again while retaining the other section.

MCP clients can call `gene_evidence(query="SPP1", sections=["expression","diseases","drugs"])` for schema `biomcp.evidence.v1`. The sections select enrichment and figure evidence. Core research still runs for the gene. Call `trial_detail(nct_id="NCT00411424")` for a linked study. The Sources table describes both core calls and optional sections.

Verify with `python scripts/check.py` and `python tutorials/validate_mcp.py`. Live OMIM requires approved credentials. ClinVar and Reactome are planned extensions.
